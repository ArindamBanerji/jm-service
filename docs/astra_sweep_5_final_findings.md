## Release blockers

1. **Public dependency exposure.** FastAPI 0.115.6 constrains Starlette to >=0.40.0 and <0.42.0. The clean install resolved 0.41.3. Its file response implementation is affected by CVE-2025-62727 and its multipart parser by CVE-2025-54121. The app exposes both through the review UI and anonymous CSV uploads. The report executor starts after multipart parsing. Upgrade FastAPI to a version supporting a maintained Starlette, resolve the dependencies again, check current advisories, and test both features with that resolution. The workspace run used FastAPI 0.163.1 and Starlette 1.10.0. [FastAPI release metadata](https://pypi.org/pypi/fastapi/0.115.6/json) · [Starlette file response advisory](https://github.com/Kludex/starlette/security/advisories/GHSA-7f5h-v6xp-fcq8) · [Starlette multipart advisory](https://github.com/Kludex/starlette/security/advisories/GHSA-2c2j-9gv5-cj73)
2. **Incorrect reviewer attribution in Label Studio.** In a fresh SQLite test database, predict without an annotator followed by a verified webhook from reviewer 7 returned HTTP 200 and stored a null annotator. For a second annotation, initial verification recorded reviewer 7. An update with the same action and outcome from reviewer 8 returned 200 and kept reviewer 7. The first-verification branch learns on the original score row, and the duplicate check compares only action and outcome (`label_studio.py` lines 273–288). This distorts per-reviewer evidence used for autonomy. Resolve reviewer identity on first verification and include it when deciding whether a revision is a duplicate. Add both flows to the connector tests.
3. **Clean-checkout verification fails.** Only test_deployment.py of the eight requested suites is tracked. test_smoke.py and pyproject.toml are absent. The other committed suite, test_jm_service.py, still expects health status `ok` and creates a TestClient without entering lifespan. A default Windows Git export gave 35 passes and four failures in the two committed suites. Three deployment failures were caused by CRLF conversion of the frozen engine. Comparing exports with core.autocrlf=true and false confirmed different engine hashes and a trailing carriage return on the shell shebang only in the former. Commit the release tests, current legacy fixture, smoke client and config, declare the async test plugin in development dependencies, and enforce LF for jm_core.py and docker-entrypoint.sh. Verify the exact candidate from a fresh checkout.

**Policy warning.** Direct ingest computes category status from verified outcomes and returns action_policy from that status before applying annotator eligibility. A response can simultaneously say auto_accept and auto_accepted=false. It can also report a paused score-engine gate alongside category eligibility because core conservation measures action agreement. The connector checks the active engine gate separately and interprets the gate's warmup boolean as passing. Specify one effective per-item eligibility contract and test the differing gate states across callers. No automatic action execution was observed.

## Code quality and resources

- **High — anonymous report capacity.** Two workers bound simultaneously running analyses and renders. Each caller can already hold 10 MiB while awaiting the semaphore, with no bound on the number waiting. Queue acquisition and execution have separate 60-second deadlines. A timed-out job keeps working and holds its slot until completion. Bound admission and memory before reading payloads, enforce a single request deadline and configure an ingress body limit before multipart parsing.
- **Warning — misleading binary report metric.** In label_health/analyze.py, labels_needing_reverification counts maximum softmax scores strictly below 0.5. With the default two actions, that maximum is always at least 0.5, including complete ties. The report can therefore say zero need reverification for uniformly uncertain labels. Define and test the intended uncertainty rule.
- **Warning — persistence and cleanup.** Async request sessions roll back on failure and close through their context manager. Migrations dispose the engine. The service lifespan omits explicit pool and report executor shutdown, and legacy init_db closes the connection only on its success path. Label Studio mapping writes use a temporary file and replace under a process-local lock. Multiple writers sharing that file can lose updates.
- **SQL and secrets.** The legacy routes bind query values. The repository uses SQLAlchemy expressions. Migration SQL interpolates identifiers drawn from fixed tuples. No request-derived SQL interpolation or production secret literal was identified in these paths. Compose and the standalone smoke script contain local development credentials. The Dockerfile declares only paths as environment variables. The legacy public registration endpoint issues credentials separately from the hosted tenant system.
- **Imports and dead code.** The static pass over service modules, demo and experiment entry points found nine unused imports and two unused assignments. These include Optional in the frozen core and service, DomainConfig in the legacy loader, Any in CSV ingest, datetime/timezone and JudgmentMemoryEngine in the connector, and scored in verify_and_relearn. The latter call has side effects and must still run. No undefined-name or bare-except findings. A reference scan found no clearly unused production function after accounting for framework and HTMLParser callbacks. Some APIs are exercised only through tests or library callers.
- **Exceptions and typing.** Health converts probe failures to status, PDF falls back on native OSError, and transaction handlers re-raise after cleanup. No production debug print was found on the service request paths. Type suppressions cover CORS middleware typing, optional renderer stubs and dictionary lookup comparisons. FactorArray implements named get for score, while readonly requires items. Its list return annotation and the test's dictionary cast do not establish compatibility with readonly. Broad dict/Any annotations in connector and report code limit mypy's ability to detect malformed input.

Broad root Python COPY includes demo and test code. Neither Docker nor Podman was available for a native image run. The local PDF signature check also passes through ReportLab fallback and cannot certify native WeasyPrint output.
- The committed index has a React root and references existing JS and CSS assets. The client has a single fetch wrapper with relative /v1 paths. The compiled bundle's localhost literals are URL construction fallbacks in the router. No localhost:8000 API target was found. StaticFiles mounts last and only when dist exists. Release acceptance requires the dependency and attribution fixes, a reproducible passing candidate revision, and an image smoke run against PostgreSQL verifying migration, health, native PDF, authenticated ingest/verify and persisted data after restart.
