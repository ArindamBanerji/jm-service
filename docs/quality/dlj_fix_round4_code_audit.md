## Exact partial findings closed

- **R13:** Browser-shaped `verified_outcome` was ignored by a DTO expecting `outcome`; the browser now requires and sends `outcome`. Two API tests and browser approve/reject cases cover the wire path.
- **R45:** Reordered tags made false revisions and an unverified successor erased negative evidence. Set comparison prevents the false revision; recursive descendant evidence keeps the negative until a replacement is verified. Empty typed content is tested as a real change.
- **R03:** Connector successor missed revision provenance; it now copies a prior pointer, actor and timestamp. An image URL copy has dedicated coverage.
- **R09:** Admission previously limited only the selected file after multipart spooling. Content-Length and receive-byte checks now bound the complete request before each chunk enters the parser.
- **S4-01:** A stalled multipart or selected-file read now expires against the admission-time deadline, and both paths have slot-release tests.

The modified Playwright files (`components.spec.ts`, `fix_round3.spec.ts`, `flows.spec.ts`, `fix_round4.spec.ts`) assert the new bulk contract, signup identity and receipt lifecycle, verify lock, and malformed usage. `test_sweep3_fixes.py` only adds an optional image URL argument to its correction fixture; prior callers retain the default. `test_round4_fixes.py` exercises each backend fix on both database dialects.
